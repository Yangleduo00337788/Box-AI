## Box AI v1.0.0 — Box V1 正式发布

**发布日期**：2026-09-28 · **标签**：`v1.0.0`

Box V1 首个稳定发行版：**企业级 AI Agent / Workflow 平台**。在统一工作空间内完成智能体配置、RAG、工具与 MCP、流程编排、调试追踪与生产发布，并提供 C 端、B 端管理与 Open API。

### 核心能力

- **Agent**：Builder 调试、版本快照与发布隔离、对话 SSE（含 Tool Calling）、Embed 与 API Key 开放调用
- **知识库**：多格式文档、处理状态机、检索 / Rerank / Test Answer、对话引用
- **工作流**：可视化编排、图校验、调试与发布、Webhook
- **工具与插件**：HTTP / DB / Function / Code / MCP；插件市场、对话加号插件、官方目录上架
- **平台**：多租户与套餐（个人 / 团队）、RBAC、审计、Trace 与 Token 用量、MinIO / R2 对象存储
- **交付**：`box-web`、`box-admin-web`、`box-ui`、`box-sdk`；Docker Compose 全栈；CI 与发布门禁脚本

### 本标签重要变更

- 本地与部署统一通过仓库根目录 **`.env`** 注入配置（见 `.env.example`）
- 生产环境 **弱密钥启动拦截**；Webhook 签名校验修复；验证码默认不回显；知识库 URL 导入 **SSRF** 防护

### 快速开始

    git clone <你的仓库地址>
    cd Box_AI
    cp .env.example .env
    cd deploy && docker compose --env-file ../.env up -d
    cd ../box-server && mvn spring-boot:run -pl box-bootstrap

C 端 / B 端：在 `box-web`、`box-admin-web` 下执行 `npm install && npm run dev`（详见 README）。

### 组件版本

| 组件 | 版本 |
|------|------|
| box-server | 1.0.0 |
| box-web / box-admin-web / box-ui | 1.0.0 |
| box-sdk (JS) | 1.0.0 |

### 已知限制

- OAuth / SSO 仍为 stub，生产需接入真实 IdP
- 计费、分布式 Runtime、K8s 等属 V2 路线图，不在本版承诺范围

## Box AI v1.0.0 — Box V1 stable release

**Date**: 2026-09-28 · **Tag**: `v1.0.0`

First stable **Box V1** release: enterprise **AI Agent & Workflow** platform with workspaces, agent builder, RAG, tools/MCP, orchestration, publish governance, multi-tenancy, admin console, and Open API.

### Highlights

- **Agents**: builder, versioned publish, chat SSE (tool calling), embed & API keys
- **Knowledge**: multi-format ingest, pipelines, search/rerank/test-answer, citations
- **Workflows**: editor, validation, debug, publish, webhooks
- **Tools & plugins**: HTTP/DB/function/code/MCP, marketplace, chat plugins
- **Platform**: plans (personal/team), RBAC, audit, trace & token usage, MinIO/R2 storage
- **Shipping**: web + admin + shared UI + JS SDK, Docker Compose, CI & release-gate scripts

### Notable in this tag

- Repo-root **`.env`** loading (see `.env.example`); `docker compose --env-file ../.env`
- Production **weak-secret** guard; webhook signature fix; verification codes hidden by default; knowledge URL import **SSRF** protection

### Quick start

    cp .env.example .env
    cd deploy && docker compose --env-file ../.env up -d
    cd ../box-server && mvn spring-boot:run -pl box-bootstrap

### Versions

`box-server` **1.0.0** · frontends & `box-sdk` **1.0.0**

### Limitations

OAuth/SSO stubs only; billing, distributed runtime, and K8s are on the V2 roadmap.

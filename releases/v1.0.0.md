# Box AI v1.0.0

**发布日期**：2026-09-28  
**Git 标签**：`v1.0.0`

Box V1 首个稳定发行版：企业级 AI Agent 与工作流平台，覆盖工作空间、智能体构建、RAG 知识库、工具/MCP、流程编排、发布治理、多租户与 B 端运营。

---

## 亮点

- **Agent 全链路**：Builder 调试、版本快照、发布隔离、对话 SSE（含 Tool Calling 事件）、Embed 与 Open API（API Key）。
- **RAG 知识库**：多格式文档、处理状态机、检索与 Test Answer、Rerank、Agent 绑定与引用。
- **Workflow**：可视化编排、校验、调试与发布；Switch 等节点与 Webhook 集成。
- **工具生态**：HTTP / DB / Function / Code / **MCP**；插件市场、对话加号插件、官方目录上架。
- **平台能力**：多租户与套餐（个人/团队）、RBAC、审计日志、追踪与 Token 用量、对象存储（MinIO / R2 热切换）。
- **交付与质量**：`box-web` / `box-admin-web` / `box-ui` / `box-sdk`、Docker Compose 全栈、CI 与 [发布门禁](../test-fixtures/RELEASE-GATE.md) 自动化脚本。

## v1.0.0 补丁说明（本标签含）

- 本地开发：仓库根目录 `.env` 自动加载（见 `.env.example`）；部署 `docker compose --env-file ../.env`。
- 安全：生产环境弱密钥启动校验；Webhook 签名校验修正；验证码默认不回显；知识库 URL 导入 SSRF 防护。

## 快速开始

```bash
cp .env.example .env
cd deploy && docker compose --env-file ../.env up -d
cd box-server && mvn spring-boot:run -pl box-bootstrap
```

详见 [README](../README.md) / [README_en](../README_en.md)。

## 已知限制（V2 方向）

- OAuth / SSO 仍为配置占位与 stub，生产需接入真实 IdP。
- 计费与分布式 Runtime、K8s 一等能力在路线图中，未包含在本发行版承诺内。

## 升级与校验

- 从源码构建请 checkout 标签 `v1.0.0`。
- 建议跑通：`.\test-fixtures\scripts\run-release-gate.ps1`（或 `run-release-gate.sh`）。
